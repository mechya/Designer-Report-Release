## Report a bug

1. Check the [open issues](https://github.com/mechya/Designer-Report-Release/issues) — someone may already have reported it.
2. If not, open a **[bug report](https://github.com/mechya/Designer-Report-Release/issues/new?template=bug_report.yml)**.

Helpful details:

- the app version (**Help → About Designer Report**) and where you installed it from (Microsoft Store or installer);
- Windows or macOS version;
- the steps to reproduce the problem, and what you expected instead;
- the messages in the **Console** and **Errors** tabs at the bottom of the window;
- if possible, a small `.jrxml` file that shows the problem (please remove any private data first).

## Suggest a feature

Open a **[feature request](https://github.com/mechya/Designer-Report-Release/issues/new?template=feature_request.yml)** and describe what you want to do and why.

## Security

If you find a security problem, please do not describe it publicly in an issue. Open an issue that only says you have a security report, and you will be contacted.

## Response times

Designer Report is developed by one person in spare time. Issues are read and answered as soon as possible, but there is no guaranteed response time.
